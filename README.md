# Stratospheric smoke observations over Haifa performed during 2017/2018 and observed by EARLINET network

> This repository is archived. The dataset is published on Zenodo with DOI
> [10.57837/actris-ares/hs4p-s598](https://doi.org/10.57837/actris-ares/hs4p-s598):
> please cite it and download it from there. The content below is kept unchanged for reference.

This dataset provides stratospheric smoke observations over Haifa performed during 2017/2018 using a PollyXT multi-wavelength Raman and polarization lidar and observed by EARLINET network. The measurements were funded by the German-Israeli Foundation, with additional support from the Norman and Helen Asher Fund and the Ollendorff Minerva Center.
